Итоговый проект — Планировщик задач

В папке `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Папка `web` содержит файлы фронтенда.

О проекте:
Этот проект — простой планировщик задач с веб-интерфейсом и API.
Позволяет создавать, обновлять, удалять и получать задачи с возможностью повторения по заданному правилу.
Данные хранятся в SQLite базе.

Структура проекта:
main.go — точка входа, запускает сервер и инициализирует базу данных.
pkg/db — работа с базой данных: инициализация, CRUD операции с задачами.
pkg/api — HTTP API обработчики, принимают запросы, обрабатывают логику и взаимодействуют с БД.
pkg/server — настройка и запуск HTTP сервера.
web — статические файлы фронтенда (HTML, CSS, JS).
tests — тесты для проверки работы API.
Как работает проект

При старте запускается сервер на порту по умолчанию 7540 (можно изменить через переменную окружения TODO_PORT).
Сервер инициализирует базу данных (создаёт файл и таблицу, если их нет).
API обрабатывает запросы на создание, получение, обновление, удаление и отметку задач как выполненных.
Задачи можно создавать с датой и правилом повторения, например, повторять через несколько дней или раз в год.
Фронтенд взаимодействует с сервером через API и отображает задачи.
Основные фишки

Повторяющиеся задачи: автоматический пересчёт даты следующего выполнения по заданному правилу.
Простое REST API: стандартные HTTP методы для работы с задачами (POST, GET, PUT, DELETE).
Статический фронтенд: отдельная директория с веб-страницами, отдаваемыми сервером.
SQLite: лёгкая и простая база данных для хранения задач.
Как запустить

Клонировать репозиторий
Перейти в корень проекта
Запустить команду:
go run main.go
Перейти в браузере по адресу:
http://localhost:7540
Использовать веб-интерфейс или API для управления задачами.
